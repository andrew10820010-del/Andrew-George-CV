# Andrew George Sabry – CV website

`index.html` is fully self-contained: every photo, certificate and screenshot is embedded inside it,
so the site shows all images even if the `assets` folder is not uploaded.

## Update your GitHub Pages site
1. Open your repo (Andrew-George-CV) > Add file > Upload files.
2. Drag in `index.html` (replace the old one) and, if you like, the `assets` folder and `.nojekyll`. Commit.
3. Wait 1-2 minutes, then hard-refresh the page (Ctrl+F5).

`assets/` holds the original images for your own use; the page does not need them.
