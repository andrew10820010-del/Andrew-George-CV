# Andrew George Sabry – CV website

Static site (no build step). Files:
- index.html – the whole website
- assets/photo.jpg – your portrait (already included; replace it any time with a square photo, 600x600+ px)
- assets/*.jpg – certificate images. Add more using these exact names and they replace the placeholders:
  (all certificates and Breadfast photos are already included)

## Publish on GitHub Pages
1. Create a repo named `<your-username>.github.io` (or any name).
2. Upload everything in this folder (keep the `assets` folder and the `.nojekyll` file).
3. Repo Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
4. Your site goes live at https://<your-username>.github.io/ (or /<repo-name>/) within a minute or two.
